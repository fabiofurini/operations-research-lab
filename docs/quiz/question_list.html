orl-f-015 · level teorema · notes
Primal $\max\{\sum_j c_jx_j : \sum_j a_{ij}x_j \le b_i,\ x \ge 0\}$; for feasible $\bar x$ and dual-feasible $\bar\pi$ let $\bar s_i = b_i - \sum_j a_{ij}\bar x_j$ (slacks) and $\bar c_j = c_j - \sum_i a_{ij}\bar\pi_i$ (reduced costs). The pair is optimal if and only if:
  1. $\bar\pi_i + \bar s_i = 0$ for every $i$ and $\bar x_j + \bar c_j = 0$ for every $j$
  2. $\bar s_i = 0$ for every $i$ and $\bar c_j = 0$ for every $j$
  3. $\bar s_i > 0 \Leftrightarrow \bar\pi_i = 0$ for every $i$ and $\bar x_j > 0 \Leftrightarrow \bar c_j = 0$ for every $j$
  4. $\bar\pi_i\,\bar s_i = 0$ for every $i$ and $\bar x_j\,\bar c_j = 0$ for every $j$
Explanation. These are the complementary slackness conditions. They give implications (slack constraint $\Rightarrow$ null dual), not equivalences: degeneracy is allowed, so the third option is too strong.
